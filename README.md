## 本次更新 · V159

- 私信改为剧情进度问候。已相遇的男主按玩家读过的情节来信，每次提供三个回复选项，各有不同回应，聊完自然收尾并保存。不接入 AI，不需要 API 或额外订阅。
- 风信保留原青绿绘卷画风，三个偃甲雀分别对应风闻、私信和委托；亭子图中的莲花已移除，右侧高立牌改为嵌在桌前的横牌。
- 九州风闻每天一则。新增366篇不改变主线与人设的日常散闻，保留原有大纲人物传闻；从此版本开始记录已投递内容，滚动一年不重复。需保留当前浏览器的本地存档。
- 大厅“战斗”更名“试炼”，试炼与商城使用各自独立图标。“星渊试练”以巫渊星河、祭台遗迹为背景，无山景、风铃或铜铃。
- 试炼使用宫商角徵羽五音，可爬高层、胜后选一项祝福；每五层有守关，中途自动保存，失败可免费重试，重新开始前会确认。
- 灵宠修正颈部、前肘和后膝绑定，调整喂食、抚摸、跳跃、修炼与低精力动作；尾根参与整尾左右摆动，胸腹及后颈背毛分区运动。保留自然眨眼、暖铜旋转按钮，不提供放大按钮。
- 章节维持2D背景；九州地图不显示侧边路径字列；风信无顶部标题和日期，返回按钮与卷札图标保留。

存档仍保存在当前设备、当前浏览器中；更换浏览器或清除网站数据会影响本地进度与年度投递记录。

此仓库只同步可运行的网页游戏文件，不包含游戏大纲、Unity编辑工程、原始3D模型或未发布素材源文件。
