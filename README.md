# 星渊引 · 镜中试炼更新

## 本次调整

- 重新排布思念配队页，采用完整卡面与三人同行栏，减去繁复边框和伤害算式。
- 五音牌加入古琴、琵琶、笛、鼓、笙插画；乐器只是牌面主题，不是五音与乐器的固定对应。
- 保留玩家提供的镜魇模型，放大展示，加入受击裂纹与碎片、击败后的大幅碎裂和消散。
- 移除暂押显示。每个固定关卡的首通镜华只领取一次；重复挑战不重复发放。已获得镜华不会因后续失败被没收。
- 失败后确认重新开始消耗10体力；取消、体力不足或重复确认不扣费。旧收益与已通关记录保留迁移。
- 修正灵宠修炼时头颈带动下巴变扁的问题，保留闭眼状态和固定位置的小球。
- “前尘旧梦”竖排标题稍向下调整。
- 镜华阁使用新的月白浅木庭院背景，增加项链、耳坠、头冠图鉴预览。

- 补齐新界面需要的嵌入字库，避免网页版漏显示“链、坠、佩”等字。

## 尚未开放

镜华阁目前仅展示饰品图片，不扣镜华。灵石、语音、信件和饰品兑换，以及给角色实际佩戴饰品的功能尚未开放。现有四关不是全年运营内容；后续关卡与兑换价格仍需完善。

## 存档与访问

游戏仍使用兼容的161.0.0存档版本，以链接中的build标识区分更新。请不要清理浏览器站点数据，以免丢失本地进度。此版本没有新增真实支付。

静态站点的访问速度仍取决于网络环境；本次界面与战斗更新不代表已解决中国大陆访问GitHub的问题。
