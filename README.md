# 星渊引 · 乙女游戏开发预览

[进入最新网页预览](https://voidverse-studio.github.io/Tale-of-the-Star-Abyss-Pages/)

本次更新继续沿用 V161 存档格式，由页面的构建标识区分更新。请保留浏览器存档，不要为更新清除网站数据。

## 本次功能

- 章节剧情支持自动播放和跳过；遇到选择、小游戏或本章结尾会停下，不代选、不代付，也不直接跳进下一章。
- 男主私信改为带各自头像的短信式对话，可选择回复、查看对话历史；内容按人物设定重写。
- 巫渊试炼从底部第一层向上攀登，可滑动查看石台并定位当前层，背景水面有局部流动效果。
- 每层开战前可配置三张思念，查看敌方五音与克制建议，或选择一键建议。进入战斗后锁定原队，包括已存档但尚未出手的战斗；下一层可以重新配置。
- 月卡全程自动可沿用阵容跨层，自动结算并选择免费星蕴；手动停止、失败、权益到期、离开页面或退到后台会停止。原本的单层自动仍可使用。自动不会购买、升星或消耗养成材料。
- 防护数值统一称为“护援”：它是技能产生的临时护盾，初始为零，受到攻击时优先消耗；点击问号可看获得方式。
- 赤焰缩小、修炼姿态调整、头部鬃毛随风、庭院闲逛与流动火焰尾巴；喂食、玩耍、抚摸和修炼使用不同的原创合成互动音效，并遵守声音开关。
- 巫渊敌影采用作者提供的镜魇 FBX，保留原始造型、UV 和 4K 贴图，加入悬浮待机、抬手施法和受击动作。原先的临时怪物不再用于试炼。
- 镜魇的衣料、青铜碎镜和镜面采用分区材质；贴图保持 4K 导入，并使用高质量压缩、各向异性过滤和分级纹理，兼顾近看细节与远看稳定性。
- 试炼场地增加有实体厚度的石台、断柱、阶梯、崖壁和流动水面；五音技能具有蓄力、飞行、命中和消散阶段，敌袭从镜魇的施法手发出。保留既有回合制结算、升星与存档规则。

## 预览边界

这是持续开发中的测试作品，不是商业手游成品。男主思念卡仍为二维角色美术；本轮三维制作集中在作者提供的镜魇、试炼场地和战斗演出。当前角色美术、镜头与动作精度不等同于《王者荣耀》或《恋与深空》。学习其交互思路，不使用这些作品的游戏素材，也不与其关联。

月卡与商店仅用于本地功能测试，未接入真实支付，请勿提交付款信息。人物配音不在本次更新中；灵宠音效是原创合成声音，不是人物配音或真实动物录音。

网页使用较大的 Unity 资源，首次加载需要时间。不同手机、微信内置浏览器的内存和性能尚未全面认证；若浏览器因内存不足关闭，请使用桌面浏览器预览。不要通过清空存档来解决加载问题。
